# School ERP UI/UX Design System Documentation

## Palette & Typography

- **Primary**: Deep Navy (`#0f172a` / `#102a43`)
- **Supporting**: Slate, Neutral Gray (`#f8fafc`), Crisp White
- **Semantic Indicators**:
  - Green (`#166534` / `#f0fdf4`): Success, Paid, Present
  - Amber (`#92400e` / `#fffbeb`): Warning, Pending, Late
  - Red (`#991b1b` / `#fef2f2`): Overdue, Absent, Critical Alert
  - Blue (`#1e40af` / `#eff6ff`): Informational, Scheduled

## Key Features
1. **School Command Center (`/school`)**: Operational dashboard with 4 core gauges, Attention Required action center, daily schedule timeline, and interactive Recharts graphs.
2. **Student 360° View (`/school/students/[id]`)**: Flagship 360 profile for STU-1024 (Rahul Sharma) with aggregate gauges, 10 tabs, timeline, and AI insights.
3. **Teacher Classroom Attendance (`/teacher/attendance`)**: Visual one-tap Present / Absent / Late toggle grid with real-time recalculating counters.
4. **Admissions CRM (`/school/admissions`)**: Interactive applicant pipeline from Enquiry to Enrollment.
5. **Parent Mobile App (`/parent-mobile`)**: Multi-child profile switcher (Rahul 10-A / Ananya 6-B), fee payment simulator with PDF receipt viewer.
